# Tilawah for Android

Tilawah is a free, offline-first Quran and deen companion: reading, recitation with on-device speech recognition, hifz with spaced repetition, prayer times and alerts, adhkar, hadith, tajweed and more. No accounts, no ads, and everything you do stays on your phone.

**[Download the latest APK](https://github.com/ShadmanArafin/Tilawah-releases/releases/latest)** · [Open the web app](https://tilawah-tau.vercel.app)

## Installing

1. Open the latest release above and download `Tilawah-v….apk` on your phone.
2. Open the file. Android asks you to allow installs from your browser or file manager; allow it once.
3. Android 7.0 or newer is needed.

Updates install over the old version and keep your progress. The app checks this page once a day and tells you when a new version is out (nothing about you is sent).

This repository holds only the release files; each release lists what changed.
